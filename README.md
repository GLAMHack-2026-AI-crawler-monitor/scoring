# scoring

Scores every IP address in a web access log (CSV) for bot-like behaviour.

## Quick start

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 score_bot_ips.py synthetic_stress_log_sample.csv --out ip_scores_sample.csv
```

This reads `synthetic_stress_log_sample.csv` (a 1,000-line sample log) and writes
`ip_scores_sample.csv`, one row per IP with a bot score (0-5), a label, and the
reasons behind it. See `BOT_SCORING_NOTES.md` for the full developer notes: input
format, how the scoring works, converting other log formats, and the dashboard.

## Dashboard

`dashboard/` is an [Observable Framework](https://observablehq.com/framework/) site
that visualises the `ip_scores*.csv` output (needs Node.js). It reads its dataset
list from `dashboard/docs/datasets.config.json`, which for now lists only
`ip_scores_sample.csv` (generated by the Quick start command above).

```bash
cd dashboard
npm install
npm run dev      # preview at http://localhost:3000, live-reloads
npm run build     # static site in dashboard/dist/
```

See section 11 of `BOT_SCORING_NOTES.md` for how to add more datasets.

## Python/matplotlib dashboard

`plot_ip_scores.py` is a lightweight, no-Node.js alternative to `dashboard/`.
It reads a `score_bot_ips.py` output CSV and steps through the same charts
(summary cards, score distribution, requests vs. score, request mosaic) one
at a time: close a window to see the next one.

```bash
python3 plot_ip_scores.py ip_scores_sample.csv
python3 plot_ip_scores.py ip_scores_sample.csv --save-dir plots/   # save PNGs instead
```
