# Web server access log user/bot scoring

Scores every IP address in a web access log (CSV) for bot-like behaviour.

## Quick start

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

```bash
python3 src/score_bot_ips.py data/synthetic_log_sample.csv --out data/ip_scores_sample.csv
```

This reads `data/synthetic_log_sample.csv` (a 1,000-line synthetic, made-up
sample log) and writes
`data/ip_scores_sample.csv`, one row per IP with a bot score (0-5), a label, and the
reasons behind it.

## Producing the CSV from a web server log

`score_bot_ips.py` expects a CSV with columns `row_id, timestamp, ip, method,
path, status, bytes_sent, user_agent, referrer`. `parse_apache_log.py`
converts an Apache/Nginx "vhost combined" access log into that format:

```bash
python3 src/parse_apache_log.py web_server_access.log --out data/access_log.csv
```

Then run `score_bot_ips.py` on the resulting CSV as in Quick start above.

## Python/matplotlib graphs generator

`plot_ip_scores.py` reads a `score_bot_ips.py` output CSV and generates charts:

* summary cards
* score distribution
* requests vs. score
* request mosaic (shuffled, and sorted by score)

either one at a time (close the graph window to see the next one):

```bash
python3 src/plot_ip_scores.py data/ip_scores_sample.csv
```

or as image files in the `plots` folder:

```bash
python3 src/plot_ip_scores.py data/ip_scores_sample.csv --save-dir plots/
```

## Dashboard

`dashboard/` is an [Observable Framework](https://observablehq.com/framework/) site
that visualises the `ip_scores*.csv` output (needs Node.js). It reads its dataset
list from `dashboard/docs/datasets.js`, which lists `data/ip_scores_sample.csv`
(generated by the Quick start command above) and
`data/ip_scores_crawler_monitor_sample.csv` (scored from the GLAMhack
crawler-monitor sample log in `data/crawler_monitor_sample_logs_synthetic_generated with Claude_fixed.csv`,
see `data/README_Datensatz_synthetic_sample_log.md`).

```bash
cd dashboard
npm install
npm run dev      # preview at http://localhost:3000, live-reloads
npm run build     # static site in dashboard/dist/
```

## Developer tools

`generate_synthetic_log.py` blows up a small base access-log CSV into a much
larger synthetic one, for stress-testing `score_bot_ips.py` at realistic data
volumes (e.g. ~1 GB). It resamples the base rows with replacement and shifts
the last IP octet on each repeat, so the result has more unique IPs than a
plain concatenation would — a harder, more realistic case for the per-IP
grouping than just repeating the same addresses.

```bash
python3 src/generate_synthetic_log.py --base data/synthetic_log_sample.csv --out data/synthetic_stress_log.csv --target-bytes 1100000000
```
